# Анализ потребления электроэнергии в городе Ростове-на-Дону

Этот проект анализирует данные о потреблении электроэнергии в городе Ростове-на-Дону, с целью поиска закономерностей. Он использует библиотеки `pandas`, `numpy`, `matplotlib`, `seaborn` и `scipy.stats`.

## Описание

Цель проекта — исследовать распределение потребления электроэнергии, выявить аномальные паттерны потребления, проанализировать работу электросчетчиков и проанализировать потребление электроэнергии в зависимости от времени суток.

## Структура проекта

*   `main.ipynb` — это файл Jupyter Notebook, содержащий код для генерации данных, анализа и визуализации.

## Генерация данных

Данные генерируются с помощью `numpy` и `pandas`, для того что бы провести анализ.
Все сгенерированные данные имеют схожее распределение, но при этом у них есть свои особенности.  
Данные о потреблении моделируются с использованием базового значения, отклонений и пиков, которые зависят от времени суток, с учетом индивидуальных особенностей пользователей.

## Анализ

Для анализа данных я использовал:

*   `pandas` для обработки табличных данных.
*   `matplotlib` и `seaborn` для построения графиков и визуализации.
*   Статистический тест (t-тест) и коэффициент корреляции.

Основные выводы:
 *  Среднее потребление электроэнергии меняется в зависимости от времени суток, с пиком вечером.
 *  Наблюдается взаимосвязь между типом счетчика и потреблением, и между годом выпуска счетчика и потреблением.
 *  Были выявлены пользователи и временные промежутки с аномальными значениями.

## Визуализация

*  **Суммарное почасовое потребление:** Линейный график суммарного потребления энергии по часам, для общего представления.
*  **Потребление по улицам:** Столбчатая диаграмма показывает суммарное потребление энергии по улицам, с возможностью сравнить потребление на разных улицах.
*  **Распределение потребления по типам счетчиков:** Boxplot показывает распределение потребления для разных типов счетчиков, а также разброс значений.
*  **Зависимость потребления от года**:  Линейный график показывает зависимость среднего потребления от года выпуска счетчика.
*  **Процент просроченных счетчиков:** Горизонтальная столбчатая диаграмма, показывает количество просроченных счетчиков на каждой улице.
*  **Сравнение улиц:** Линейный график, где показывается сравнение потребления на 2х улицах, с макс и мин потребелние.
*  **Гистограмма**: Гистограмма общего потребления, и выделенным значением процентиля.


## Аномалии

Выявление аномалий потребления — сложный процесс, на который могут влиять различные факторы, как:
 *  Состояние электропроводки внутри дома, и в целом по улице.
 *  Состояние трансформаторных будок.
 *   Погодные условия.
 *   День недели, и праздники.
 *   Состояние счетчиков, что и является одним из объектов проверки.

  Этот анализ позволяет проверить, есть ли проблема в электросчетчиках или недобросовестных потребителях, которые потребляют несвойственное для них количество электроэнергии.
